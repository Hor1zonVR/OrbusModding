# Claude coding assistant guide

Read [AGENTS.md](AGENTS.md) first. Then consult [docs/getting-started.md](docs/getting-started.md), [docs/game-systems.md](docs/game-systems.md), [references/core-symbols.json](references/core-symbols.json), and the [public source index](references/open-source-mods.md).

This repository contains reverse-engineered **metadata**, not a stable, runtime-verified public game API. Always check build identity, mod loader and actual implementation. Do not invent undocumented symbols, endpoints, server permissions or ModCore settings interfaces.

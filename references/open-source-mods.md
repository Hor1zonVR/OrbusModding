| [OrbusAbilityLabels](https://github.com/Hor1zonVR/OrbusAbilityLabels) | Labels and game-object UI |
| [OrbusAutoMount](https://github.com/Hor1zonVR/OrbusAutoMount) | Mount-related client behavior |
| [OrbusWeaponAdjustments](https://github.com/Hor1zonVR/OrbusWeaponAdjustments) | Weapon adjustment experiments |
